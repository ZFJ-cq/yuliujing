数据与隐私

语流镜在本机完成全部识别与计算，不采集、不上传、不存储任何音频或文本，无第三方 SDK / CDN / 字体 / 统计脚本；localStorage 仅保存「目标时长」与「自定义填充词」两个设置。音量波形不录制、不落盘。

如实说明：Chrome / Edge 的 Web Speech API 由浏览器厂商实现，部分版本会把音频片段送往厂商云端完成识别，这是浏览器行为而非本应用行为。

使用与部署说明

语流镜 · MVP 版本 · 三个核心功能：实时计时与语速曲线、转写高亮、反馈卡导出

① 怎么用

  1. 选目标时长（3 / 5 / 8 / 10 / 15 分钟，或自定义），可补充自己的口头禅。
  2. 点「开始演练」并允许麦克风；对着麦克风正常讲即可。
  3. 结束后自动生成反馈卡，点「导出为图片」保存分享。空格键可开始 / 结束。

② 判读口径

  • 语速：按最近 15 秒滚动窗口计算「字 / 分钟」；中文舒适区取 180–260 字/分，低于 150 偏慢、高于 320 偏快。
  • 字数：只统计中日韩汉字与字母数字，不计标点与空白。
  • 填充词：默认「那个 / 然后 / 就是 / 嗯 / 啊」，可追加自定义词，按出现次数计。
  • 长停顿：两次识别结果之间静默超过 1.5 秒 记为一次；因浏览器按句返回结果，停顿为估算值。

③ 浏览器与降级

Chrome / Edge 支持 webkitSpeechRecognition（zh-CN），为完整模式；Safari / Firefox 自动切换为「纯计时 + 手动标记」：点按钮补记口头禅与长停顿，并可粘贴讲稿估算平均语速。麦克风被拒绝时同样自动降级，计时不受影响。

⚠ 网络与地域提示：该识别后端由浏览器厂商提供（Chrome/Edge 走 Google 语音服务），国内网络常被拦截或超时，表现为「状态条长时间无文字 / 指标全 0 / 提示 network 错误」。此时应用会自动切换为内置的离线识别（Vosk·本地模型，无需联网）：检测到 network 错误或开练数秒仍无文字时，会提示并可一键切换；首次使用需下载约 40MB 中文模型（同源托管，仅一次性）。若未放置模型文件则退回「手动标记」模式。另外，直接双击 file:// 打开页面时麦克风与识别均不可用，请通过 http://localhost 或 HTTPS 访问。

④ 部署到 GitHub Pages

  • 把本 index.html 放到仓库根目录 → Settings → Pages → Deploy from a branch → main / root → Save。
  • 访问 https://<用户名>.github.io/<仓库名>/。必须用 HTTPS 或 localhost，file:// 下麦克风与语音识别不可用。
  • 本地预览：python3 -m http.server 8080，再开 http://localhost:8080。无需 npm install、无需构建。

⑤ 隐私（请务必看）

本应用自身不采集、不上传、不存储任何音频或文本，无第三方 SDK / CDN / 字体 / 统计脚本；localStorage 只保存「目标时长」与「自定义填充词」两个设置。音量波形不录制、不落盘。

⑥ 离线识别（Vosk）部署说明

为保证国内可用且「音频不出浏览器」，本应用内置 Vosk 离线中文识别作为 Google 识别不可用时的自动兜底。只需两个同源文件（零外部请求、零 CDN）：

  • vosk/vosk.js —— vosk-browser@0.0.8 的 UMD 构建（约 5.8MB，wasm 已内联，不需要额外的 .wasm 文件）。
  • model/model.vosk —— 中文小模型 vosk-model-small-cn-0.22 打包成的 tar.gz（约 40MB，文件名故意不带 .gz 以避开 CDN 的 gzip 处理）。
  • 仓库根目录放一个 .nojekyll 空文件，避免 GitHub Pages 的 Jekyll 处理干扰。

首次切换离线识别时会下载约 40MB 模型（只在浏览器缓存里，不上传），第二次基本秒开。识别引擎来自 vosk-browser（Apache-2.0），语言模型来自 Vosk 官方中文 small 模型。
